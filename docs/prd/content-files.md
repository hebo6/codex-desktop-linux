# 内容与文件

## Markdown

本节规则统一适用于问题输入预览、已发送的用户问题、AI 回答、活动详情和 Markdown 文件预览，各场景可以按照自身空间约束采用文档或紧凑布局

支持段落、标题、强调、删除线、列表、任务列表、引用、表格、分隔线、行内代码、代码块、图片和链接

代码块头部显示语言、复制和折行操作，长代码经过视口时头部保持可见

已完成最终回答中标记为 `bash`、`sh` 或 `zsh` 的非空代码块在头部显示执行操作，其他 Markdown 场景和流式回答不显示

存在活动模型回合或 Shell 命令时禁用执行，点击可用的执行操作后在代码块内打开小型确认框，提示命令将在当前项目中不受沙箱限制地运行，默认聚焦取消，点击外部或按 `Escape` 关闭

确认后复用 `thread/shellCommand` 执行代码块内容，执行记录和输出完全来自 app-server 的回合与活动通知，客户端不自行追加记录

代码正文使用等宽字体和固定行高，默认横向滚动且不将横向滚动链传递给消息流，用户可以切换折行

表格可以在不改变普通正文宽度的前提下使用更大的可用水平空间，起始边缘仍与正文对齐

表格在可用宽度不足时内部横向滚动，并提供复制全部操作，鼠标悬浮或键盘焦点进入后显示，粗指针环境中直接可见

任务列表只读

原始 HTML 忽略，危险链接或嵌入内容阻止渲染并说明原因

流式阶段未闭合代码块保持代码样式，不反复改变已稳定内容的布局

## 链接行为

| 链接类型 | 行为 |
| --- | --- |
| 当前服务器可读取的代码或普通文本 | 内置源码视图 |
| 当前服务器可读取的 Markdown、JSON 或 SVG | 预览与源码双视图 |
| 当前服务器可读取的 HTML | 内置源码视图，并可使用系统浏览器打开 |
| 当前服务器可读取的位图 | 内置图片预览 |
| 当前服务器可读取的 PDF | 内置 PDF 预览 |
| 网页 `http` 或 `https` | 确认后使用系统浏览器打开 |
| 未支持文件类型 | 显示元数据并提供另存为 |
| 无法识别或危险协议 | 阻止打开并说明原因 |

网页确认框显示完整域名和规范化 URL，可以在本次运行期间信任该域名

远程路径必须显示对应服务器和工作区，不得呈现为本机文件

## 文件打开

加载期间显示文件名、服务器、路径和骨架内容，失败后提供重试和复制路径

同时支持预览和源码的文件使用并列视图控件明确显示当前状态，不使用动作式切换文案

Markdown、JSON 和 SVG 默认进入预览，链接携带行号、列号或行范围时默认进入源码

新打开文件时根据文件类型和定位信息重新选择默认视图，不继承上一个文件的视图

同一文件切换视图时保留源码搜索、折行和行定位状态，工具栏只显示当前视图有效的操作

文本超过预览限制时可以只显示开头，并明确标记内容已截断

保存大型文件前，确认框展示服务端报告的大小和保存位置

## 文本查看器

查看器显示文件名、相对路径、语言、编码、换行符、大小和最后修改时间

支持行号、跳转行、查找、复制选区、复制路径、切换折行和另存为

### 文件定位格式

| 格式 | 示例 | 行为 |
| --- | --- | --- |
| `路径:行号` | `src/App.tsx:42` | 定位并高亮第 42 行 |
| `路径:行号:列号` | `src/App.tsx:42:7` | 定位并高亮第 42 行，同时提示第 7 列 |
| `路径:起始行-结束行` | `src/App.tsx:42-45` | 定位并高亮第 42 至 45 行 |
| `路径#L行号` | `src/App.tsx#L42` | 定位并高亮第 42 行 |
| `路径#L行号C列号` | `src/App.tsx#L42C7` | 定位并高亮第 42 行，同时提示第 7 列 |
| `路径#L起始行-L结束行` | `src/App.tsx#L42-L45` | 定位并高亮第 42 至 45 行 |

`#` 片段格式中的 `L` 可以省略，列号也可以使用冒号连接，如 `src/App.tsx#42:7`

上述格式适用于绝对路径、相对路径、`file` URL 和 Windows 绝对路径

路径包含空格时，Markdown 链接目标使用尖括号包裹，如 `[源码](<My Project/App.tsx:42>)`

行号和列号必须为正整数，范围结束行不得小于起始行

检测为二进制或编码无效时切换到未知二进制视图

## HTML 查看器

HTML 在应用内只显示未经格式化的原始 UTF-8 源码，不提供预览视图

用户可以显式将 HTML 交给系统默认浏览器打开

应用将原始文件内容写入 `/tmp` 下的应用专属临时目录，不把远程路径映射为本机路径

浏览器直接加载该临时 HTML，不额外复制或改写工作区内的相对资源

## JSON 查看器

JSON 预览显示格式化后的结构，源码视图显示未经格式化的原始文本

格式化失败时预览保持原始内容，不用推测或修复无效结构

## 图片查看器

支持 PNG、JPEG、GIF、WebP 和经过安全处理的 SVG

SVG 预览使用安全处理后的图像，源码视图显示未经修改的原始 XML

提供适应窗口、原始尺寸、放大、缩小、旋转和另存为

缩放以指针位置为中心，只有图片大于视口时才启用拖动平移

## 保存

保存使用系统另存为对话框，默认文件名来自远程路径并清理非法字符

取消或失败后不保留无效目标文件

同名文件使用系统覆盖确认，不静默改名
