# 对话

## 顶栏

顶栏固定在主内容区顶部

顶栏按系统布局在两端放置窗口控制，窄窗口在标题前显示侧边栏按钮

会话标题、项目上下文和运行状态由窗口与导航规范定义的活动标签呈现，顶栏不重复显示标题

右侧显示剩余限额圆环和设置入口，不显示连接状态

服务端更新会话标题时使用淡入替换，不改变历史消息布局

## 消息流

消息流位于顶栏与输入区之间，内容列水平居中

消息列和输入区使用同一水平内容轨道，在各响应式断点保持左右边缘一致

首条消息上方保留清晰空间，同类型消息间距小于不同角色或活动组间距

用户消息右对齐，AI 回答和活动左对齐

用户消息使用有限宽度气泡，AI 回答不使用气泡或卡片背景，直接在消息列中展示内容

消息操作区在使用精细指针时随悬浮显示，在键盘焦点进入时立即显示，在粗指针环境中直接可见

消息操作按钮默认只显示图标，使用精细指针悬浮按钮或键盘焦点进入按钮时显示文字提示，提示不得改变消息操作区尺寸

消息操作区打开菜单或浮层后保持可见，直到浮层关闭且焦点离开

消息操作区的显隐不得改变消息高度、后续回合位置或当前滚动锚点

提问时间和回答时间统一按当前本地时间格式化：不足 30 分钟显示刚刚或 `N分钟之前`，不足 24 小时显示 `N小时之前`，其余显示 `YYYY-MM-DD HH:mm`

每个回合由用户问题、活动和对应 AI 回答组成，用户问题只在消息流中的原始位置展示

用户通过历史问题导航跳转后，目标回合的问题定位到内容区顶部

消息流使用浏览器原生滚动范围，滚动位置到达该范围末端时视为已在底部

用户主动发送新问题时，无论发送前是否在底部，都在问题后添加按实际布局计算的可消耗留白，使问题顶部与空会话首问位置一致，同时定位到新的滚动范围末端并恢复自动跟随

最终回答开始时，若仍在自动跟随，或用户已离开底部但当前回合的活动组标题已经完全移出可视区域顶部，则将最终回答顶部定位到空会话首问位置，并定位到新的滚动范围末端、恢复自动跟随

活动组收起动画期间持续保持最终回答顶部位置，避免活动内容收缩导致回答移出可视区域

运行中回合统一跟随活动更新和回答增长，不区分活动组、工具输出、思考内容和最终回答

运行中回合的真实内容末尾到达消息流可视区域底边且仍在自动跟随时，在内容末尾添加消息流可视高度三分之二的临时留白并定位到新的滚动范围末端；临时留白替代新问题对齐留白和常态底部安全空间，不与其叠加

临时留白出现后，活动更新和回答增长保持当前滚动位置并逐步占用可见留白；真实内容末尾再次到达可视区域底边时重新定位到滚动范围末端，继续显示同一个临时留白

真实内容末尾不包含临时留白，触底判断不得使用包含临时留白的滚动高度

用户通过滚轮、触摸、键盘或滚动条离开滚动范围末端后立即停止自动跟随，活动更新和回答增长保持当前滚动位置；除最终回答开始触发上述重新定位外，用户返回滚动范围末端或选择回到底部后恢复自动跟随

回合完成、停止或失败后删除临时留白并恢复常态底部安全空间，不执行额外滚动动画

用户可通过滚轮、触摸、键盘或滚动条在浏览器原生滚动范围内自由滚动

未在底部时显示回到底部操作，已在底部时隐藏

用户选择回到底部后定位到浏览器原生滚动范围末端

窗口尺寸或输入区尺寸变化时按新的消息流可视高度更新临时留白；仍在自动跟随且真实内容末尾越过可视区域底边时重新定位到滚动范围末端，已停止自动跟随时保持当前滚动位置

消息流始终渲染全部已加载回合，不对视口外内容使用虚拟化

## 历史加载

恢复已有会话时先加载最近一页回合，每个已加载回合必须包含服务端持久化的全部项目

最近一页完整渲染后消息流定位到历史底部

会话列表只读取摘要字段，未打开的会话不得预取正文

首屏响应解析、协议校验和投影转换不得同步重复处理同一份会话数据

存在更早回合时在消息流顶部显示低强调加载入口，用户滚动到顶部附近时自动加载

更早一页的全部项目加载完成后一次性插入消息流顶部，加载中不得展示不完整回合，插入前后保持当前滚动锚点

加载失败时保留已显示历史并在顶部提供重试，不自动连续重试

客户端不持久化会话正文或分页游标，切换标签时只在当前进程内保留已加载页面

每个回合的持久化项目按服务端顺序展示，时间信息只用于详情和完成摘要，不参与正文排序

可由回合项目恢复的思考和工具运行状态显示在活动组内

连接、重连、网络等待和令牌流速等未形成回合历史的瞬时状态显示在输入区上方的运行状态条，不写入消息历史

## 用户消息

用户消息中的文本使用安全 Markdown 渲染，结构化引用和附件摘要保持独立展示，不参与 Markdown 解析

用户消息沿用统一的 Markdown 能力和链接行为，代码块和表格在气泡宽度不足时内部横向滚动，不得撑破消息列

用户消息操作区位于气泡下方并右对齐，依次显示提问时间点和复制按钮

提问时间点与用户消息操作区同步显隐

复制按钮默认复制 Markdown 源文并保留文件或技能引用的显示名称，按住 Shift 点击时复制渲染后的可读纯文本

复制成功后图标短暂变为完成状态并向辅助技术播报，随后恢复

图片附件显示缩略图，点击打开图片预览，加载失败时显示文件名和重试

Data URL 图片只允许渲染 PNG、JPEG、GIF 和 WebP，缺少原始文件名时按实际媒体类型显示通用名称

## AI 回答

AI 回答使用安全 Markdown 渲染，流式阶段保持稳定的块级结构，完成后以最终内容校正

流式回答的当前输出末尾显示低强调脉冲点，紧随最后一个可见内容且不单独占行，回合结束后移除，减少动画模式下保持为静态圆点

回答尾部的操作区提供复制和在新会话中继续图标按钮

最新一轮最终回答的复制和在新会话中继续按钮常显，较早最终回答的按钮在使用精细指针悬浮或键盘焦点进入回答时显示

回答时间点不随最新一轮操作按钮常显，在使用精细指针悬浮或键盘焦点进入回答时显示

复制按钮默认复制 Markdown 源文，按住 Shift 点击时复制渲染后的纯文本

在新会话中继续从当前回答处分叉，最新一轮可以立即执行，从较早历史继续前显示确认

分叉成功后在当前窗口打开新会话，并显示来源会话和分叉位置提示

分叉失败时停留在原会话，不创建虚假的本地分支
