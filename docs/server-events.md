# 服务器推送消费

## 覆盖边界

固定协议中的所有服务端通知都必须在 `src/appServer/serverEventState.ts` 的 `SERVER_NOTIFICATION_POLICIES` 中声明消费模块、更新语义和恢复方式，消费分支通过 TypeScript 判别联合检查遗漏

会话正文、账户与审批沿用已有业务模块，其余状态由连接级 `ServerEventStore` 接收；收起面板、切换标签不停止接收，状态仅保留在当前进程内

服务端请求在 `interactionClient.ts` 穷尽处置，审批等待与入站通知处理分离，待处理请求数量受连接容量限制；当前客户端未提供动态工具执行器、外部认证令牌提供者和设备证明能力，对相应请求返回明确协议错误

未知方法、无效通知以及消费异常只记录安全诊断信息，不把未校验参数交给业务界面

## 状态与恢复

文本及进程输出按到达顺序追加，Token、目标、整轮 Diff 和状态快照按协议替换；带版本的只读同步拒绝旧响应，项目和队列变更触发分页查询，目标和队列在恢复持久会话时重新读取

实时条目按 itemId 记录生命周期和最终快照，原有转写增量流继续维护转写片段，两者不重复合并

会话撤回会使旧历史、分页请求和附属状态失效，再通过服务端恢复接口加载新历史；删除会话后，迟到响应不得重建已删除状态

协议没有完整事件重放能力，连接断开后运行中的瞬时状态标记为未知，Token 和 Diff 标记过期；新连接不继承旧音频、进程句柄或其他连接作用域资源

应用列表推送直接替换引用菜单中的应用快照，技能变化触发技能查询，登录成功和账户变化触发账户信息刷新

共享连接将会话通知分发到对应订阅窗口，将进程、命令、文件监听和搜索会话按发起窗口分发；全局元数据变化广播到使用该服务器的窗口

## 展示与资源

运行状态面板仅展示 `threadId` 与当前会话一致的推送及请求失败，包括剩余上下文与目标预算、队列、汇总变更、工具进度、告警和实时转写，提醒数量也仅统计当前会话；全局推送继续在后台消费，不进入此面板，未选择会话时不显示面板；详情展开后才挂载，界面刷新按短时间窗口合并

正常完成的活动与目标、目标清除等收尾状态不展示，失败、告警和待同步状态继续保留；实时会话结束后隐藏空卡片和完成状态，已收到的转写与音频内容继续可用，所有状态仍在后台消费

音频输出按服务端 PCM 参数生成内存 WAV，只有用户点击播放才创建媒体资源，切换或卸载时释放 Blob URL；CSP 仅允许 Blob 媒体，不启用麦克风、远程媒体或远控功能

记录数、实体数、文本、结构化详情和音频缓冲均有明确上限，展示内容被截断时显示提示；具体容量统一定义在 `SERVER_EVENT_LIMITS`，同步列表仅保留容量内的预览

用于拒绝迟到查询的版本号和删除标记保留到连接结束，不随展示缓存淘汰，以免旧响应重新匹配初始版本

结构化详情在序列化和截断前遮盖敏感键，SDP 只展示协商状态，附件预览保留类型及本地引用信息，不把认证凭据或媒体载荷写入日志、数据库

网关 OAuth 授权 URL 不进入事件记录，MCP 订阅仅记录订阅标识与事件方法，不保存未知事件载荷

## 验证

修改涉及的测试验证增量与快照交错、查询期间再次变更、删除和断线后的迟到响应、撤回历史、跨窗口资源归属、审批等待期间持续接收通知，以及折叠状态下持续消费和音频资源释放

协议生成物仍以固定 Schema 为唯一来源，新增只读同步响应先加入生成清单，再生成类型及运行时校验器
